**Overview**

My project is an online gift shop that offers pre-curated gift sets as an easy way for people to buy thoughtful gifts for their loved ones. Customers can browse gift sets, make a choice, and include a personal message for the recipient.

The first version will demonstrate the ordering process using sample products and pretend orders.

**Users and problem**

Putting together a gift set can be tedious and time-consuming. Sometimes, it is difficult to make ordinary items feel personal. Other times, it is simply difficult to decide what to give or what is appropriate.

The website will provide pre-curated gift sets, prices, and personalization in one place. This will be helpful to people who are too busy or simply don’t know what to gift. The whole process will be made easier.

**Essential features**

- Browsing gift section

- putting a gift set into the cart

- show order summary

- including a personal message.

**Optional features**

- Online payments

- Delivery/pickup details

- delivery tracking

- build your own gift box

- Search or filter gifts by occasion or price

- Choose a delivery date.

**Customer steps**

- Open website

- Browse gift sets

- Select a gift set

- include a personal message to the recipient (optional)

- see order summary in the cart

- Edit the selected gift set or personal message before confirming if you want to change it.

- confirm order

- display order confirmation

**Information entered and shown**

- Each order contains exactly one gift set. Customers must select a gift set before proceeding to the order summary. Changing the gift set replaces the existing selection.

- personal message is optional.

- The website displays gift pictures, and descriptions

- prices will be set in euros (€)

- gift set ordered and/message must be included in the order summary

- The website displays an order confirmation only after the customer confirms the pretend order.

**Rules and design**

- All gift sets must have a clear picture

- description and prices must be legibly attached to them.

- Customers must choose a gift set to continue.

- Personal message is optional.

- Prototype should work without a customer account

**Success test**

The first version is successful when:

- A customer can view the gift catalogue and select a gift set.

- The website prevents the customer from continuing without selecting a gift set.

- A customer can add a personal message.

- A customer can continue without adding a message.

- The order summary shows the correct gift set, price, and message.

- A customer can change their choices before confirming.

- Confirming the order displays a clear demonstration confirmation.

- The main customer steps work on a computer screen.

- Changing the gift replaces it rather than adding a second gift.

- Editing the gift set or message updates the order summary correctly.

- A customer can continue browsing when they find nothing suitable.

- The prototype works without an account.
